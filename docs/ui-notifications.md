# 提示与通知

点击操作触发的成功、失败和表单校验通过 `notify()` 显示在右上角，由 Notivue 管理关闭和 6 秒自动消失，最多同时显示 3 条。浮动通知入口为 `components/ui/alert/Notification.vue`。按钮、表单控件、布局仍使用原有组件。

页面加载失败、连接中断、只读、版本冲突等持续状态，以及权限或环境说明，使用 `components/ui/alert/Alert.vue` 留在对应内容区域。操作失败不插入页面或弹窗里的 Alert，不改变表单布局、不清除用户输入。

## 使用约定

- 通过 `type="info | success | warning | error"` 选择语义，不再手写提示框颜色、图标偏移或边框。
- 操作结果使用 `lib/notifications.ts` 的 `notify(message, kind)`；重复反馈可合并，同样的操作再次失败仍会提示。
- 已有操作错误状态可使用 `useActionFeedback(error)` 转为悬浮通知。读取失败等持续状态不要接入这个监听。
- 重试、恢复、确认等操作放在 `#actions` 插槽。图标由组件放在首行行框中，随文字行高对齐。
- 静态说明可设置 `role="note"`；错误和警告默认使用 `alert`，其他反馈使用 `status`。
- 页面提示和浮动通知均使用 Notivue 原生 `pastelTheme`，深浅模式保持 Pastel 配色。内联提示不进入通知队列，浮动通知由 Notivue 管理。

## 间距归属

- 普通页面提示与下一块内容间距为 16px。
- 表单和弹窗内容由容器的 12px gap 管理；提示不再叠加 margin。操作区与上一项间距为 16px。
- 账号恢复／入班完成结果使用悬浮通知；完成后的页面仅保留后续操作入口。
- `app-alert--section` 为前一块内容之后的说明补充 16px 间距。
- `app-alert--inset` 用于表格卡片内的提示，与卡片边缘保留空间。
- `app-alert--banner` 用于集成在工作区或窗口顶部的连续横条，外部不留卡片式间距。
- 其他明确的容器内边距由 `alerts.css` 集中管理；避免各页面重新定义提示框 display、padding 或 SVG margin。

## 验收

本地预览：`http://127.0.0.1:5173/.local/alerts-preview.html`。预览文件位于忽略的 `.local` 目录，不加入生产路由或构建。

检查操作结果是否在右上角出现，页面／弹窗是否保留输入且没有新增结果框，再检查长文案、通知关闭、自动消失和深浅主题。持续状态需额外检查加载失败、只读、版本冲突及编辑器资源失败等行内提示。

迁移时使用隔离接口检查桌面页面、恢复成功、登录表单校验、弹窗及通知关闭；不向真实接口提交诊断数据。
