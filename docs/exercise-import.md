# 题目导入指南

当前系统支持从本地 Markdown 文件和题目 JSON 备份导入练习。导入入口在课堂内使用，需要课堂教师权限；学生不能导入题目。系统没有内置洛谷、LeetCode 等外部站点抓取器，外部题目需要先保存或整理为本文档支持的文件格式。

## 导入方式选择

| 场景 | 推荐入口 | 结果 |
| --- | --- | --- |
| 一次导入多道题，快速搭课堂题单 | 练习列表的「批量导入」 | 每个文件创建一道新练习，统一保存为草稿，并按选择顺序追加到课堂末尾 |
| 正在编辑一道题，想从 Markdown 填充表单 | 练习编辑页的「导入 Markdown」 | 先预览并勾选字段，再填充当前编辑器；仍需保存题目 |
| 恢复、迁移或复制一道已编辑题 | 练习编辑页的「导入备份」 | JSON 备份填充当前编辑器；`id`、版本、排序和发布状态不会还原，仍需保存为新草稿 |

批量导入成功后不会自动发布。请先在列表中检查题面、默认语言、初始代码和源文件名，再按需要发布。

## 批量导入步骤

1. 以课堂教师身份进入「练习」页面。
2. 点击「批量导入」。
3. 选择一个或多个 `.md`、`.markdown` 或 `.json` 文件。
4. 在左侧列表确认勾选状态：
   - 存在解析错误的文件不能导入；
   - 源文件名与课堂已有题目或本批次其他题目冲突时，请取消勾选冲突项，或修改文件后重新选择；
   - 出现警告的文件可以导入，但必须先核对预览内容。
5. 在右侧预览字段。字段为空时不会覆盖，因为每个文件都会创建新题目。
6. 点击「导入为草稿」。
7. 导入完成后刷新得到新草稿列表，检查无误后发布。

服务端在同一个事务中写入本批次题目。如果任何一道题保存失败，本批次已尝试写入的内容会回滚，不会留下半批题目。

## Markdown 格式

推荐从一个一级标题开始，使用识别的章节标题组织内容：

````markdown
# 累加求和

知识点：循环、前缀和
源文件名：sum.cpp

## 题目描述

计算 1 到 n 的整数和。

## 输入格式

一个整数 n。

## 输出格式

输出一个整数。

## 输入输出样例

### 输入 #1

```text
5
```

### 输出 #1

```text
15
```

## 初始代码

```cpp
#include <iostream>

int main() {
  return 0;
}
```
````

### 可识别字段

- 题目标题：第一个未识别的一级标题，或 `题目`、`标题`、`题目标题`、`title`。
- 知识点：`知识点`、`标签`、`topic`、`tags`。
- 源文件名：`源文件名`、`学生源文件名`、`文件名`、`filename`。
- 题面：`题面`、`题目描述`、`问题描述`、`描述`、`description`。
- 输入说明：`输入`、`输入说明`、`输入描述`、`输入格式`、`input`。
- 输出说明：`输出`、`输出说明`、`输出描述`、`输出格式`、`output`。
- 样例输入：`样例输入`、`输入样例`、`示例输入`、`sample input`。
- 样例输出：`样例输出`、`输出样例`、`示例输出`、`sample output`。
- 初始代码：`初始代码`、`起始代码`、`代码模板`、`模板代码`、`starter code`。

中英文标题都支持，标题末尾可以带编号，例如 `样例输入 1`、`Input #2`。`样例`、`输入输出样例`、`示例`、`sample` 等可作为样例分组标题，其下的 `输入` / `输出` 子标题会识别为样例输入和样例输出。

`知识点`、`标签`、`源文件名`、`文件名`、`语言` / `默认语言` / `language` 也可以写成 `名称：值` 的元信息行，并放在题面开头。元信息行会被提取，不会留在题面中。

### 解析规则

- 样例输入、样例输出和初始代码保留代码块原始内容，包括缩进和空行。建议使用围栏代码块。
- 样例和初始代码段落中的普通说明文字会被忽略，并显示警告；请核对预览。
- 同一字段重复出现时会合并，中间以空行分隔，并显示警告。
- 未识别的章节会保留在题面中，例如 `提示` 及其内容。
- 代码块内的 `#` 标题和元信息行不会被解析。
- Markdown 中的 HTML 不会渲染；请使用普通 Markdown 表达内容。
- `初始代码` 代码块的语言标记可用于识别默认语言：`python`、`py`、`python3` 识别为 Python；`cpp`、`c++`、`c++17`、`c++20` 识别为 C++。
- 也可以使用元信息行指定语言，例如 `语言：Python`。若未显式指定，`.py` 源文件名会识别为 Python，否则默认为 C++。

## JSON 题目备份格式

推荐从练习编辑页的「下载题目备份」生成 JSON，再按需修改。批量导入的 JSON 需要是一个对象，九个题目字段都必须是字符串，即使为空也要写出来：

```json
{
  "title": "问候",
  "topic": "输入输出",
  "filename": "hello.py",
  "description": "读取名字并输出问候。",
  "input": "一行字符串。",
  "output": "一行问候语。",
  "sampleInput": "Codemia",
  "sampleOutput": "Hello, Codemia!",
  "code": "print(\"Hello\")",
  "language": "python",
  "starters": {
    "cpp": "#include <iostream>\nint main() {}",
    "python": "print(\"Hello\")"
  },
  "status": "draft"
}
```

字段含义：

- `title`：题目标题。
- `topic`：知识点。
- `filename`：学生源文件名；可以留空。
- `description`：题面，支持 Markdown。
- `input` / `output`：输入、输出说明。
- `sampleInput` / `sampleOutput`：样例内容，按纯文本导入。
- `code`：当前默认语言的初始代码。
- `language`：默认语言，只能是 `cpp` 或 `python`。
- `starters`：可选，可为 `cpp` 和 `python` 分别保存初始代码模板。未提供当前语言的模板时会使用 `code`。
- `status`、`id`、`version`、`position` 等备份元数据在导入时不会还原；新题目总是草稿，并追加到课堂末尾。

`description` 按 Markdown 渲染；样例和代码按纯文本展示。不要把 HTML 放入题面。

## 校验和限制

| 项目 | 限制 |
| --- | --- |
| 每批文件数 | 最多 50 个 |
| 单个文件大小 | 最大 1 MiB |
| 批量导入请求内容 | 最大 500 KiB，超出时减少勾选并分批导入 |
| 文件编码 | UTF-8；BOM、CRLF 和 LF 均可 |
| 标题 / 知识点 | 各最多 100 字符 |
| 源文件名 | 最多 80 字符 |
| 题面 | 最多 100000 字符 |
| 输入 / 输出说明 | 各最多 10000 字符 |
| 样例输入 / 样例输出 | 各最多 65536 字符 |
| 初始代码 | 每种语言最多 100000 字符 |

源文件名必须以字母、数字或下划线开头，后续可包含字母、数字、下划线、点和中划线，并以 `.cpp`、`.cc`、`.cxx` 或 `.py` 结尾；Windows 设备名（如 `con.cpp`）不允许。默认语言为 C++ 时只能使用 `.cpp`、`.cc`、`.cxx`；默认语言为 Python 时只能使用 `.py`。

源文件名在同一课堂内不区分大小写去重。如果 `sum.cpp` 已存在，导入 `SUM.CPP` 会冲突；未填写源文件名的题目不参与冲突检查。

所有字段不能包含空字符（NUL）。解析错误会显示在对应文件预览中，不会静默截断或修改内容。

## 直接调用 API

普通教学场景请使用页面导入。自动化脚本可以复用同一能力：

```http
POST /api/classrooms/{classroomId}/exercises/import
Content-Type: application/json

{
  "exercises": [
    {
      "title": "问候",
      "description": "读取名字并输出问候。",
      "language": "python",
      "filename": "hello.py",
      "code": "print(\"Hello\")"
    }
  ]
}
```

请求必须携带已登录教师会话，且账号在目标课堂拥有教师权限。API 会应用与页面相同的数量、大小、语言、源文件名和字段校验，并在事务中追加为草稿。为保证与前端行为一致，建议 JSON 对象提供全部九个题目字段和 `language`；未知备份元数据不会被还原。
