## 功能验收

已通过真实 HTTP 与 PostgreSQL 验收：

- 教师创建课堂，学生审批加入；重复加入无重复成员；非成员、其他学生与无课堂权限的管理员不能读取作品。
- 草稿题目对学生不可见，发布后可见；每名学生拥有独立草稿；旧 revision 保存返回冲突，教师可读取当前草稿。
- GCC 正常编译得到正确输出；语法错误保留原始诊断；运行后继续编辑不改变旧代码快照。
- 交互程序接收多行输入，真正关闭 stdin 后继续输出并结束；停止、非零退出、死循环、超内存、无限输出均正确分类。
- 求助和解决状态真实同步；提交固定版本不随后续编辑改变；匿名投屏不能被学生读取，撤销后不可再访问。
- 作品导出包含真实学生、练习、版本、代码与运行上下文；归档阻止后续编辑与运行。

浏览器已使用独立教师和学生会话验证：登录、编辑自动保存、断网提示和本机备份、重连同步、刷新恢复、教师看到未提交修改、真实编译输出、运行时输入与 EOF，以及匿名投屏和撤销。交互测试的预填输入与新增输入合计后输出 `sum=10`。

## Linux 隔离与故障恢复

引擎为固定上游 v1.13.3 加可复现 EOF 补丁，构建版本 `v1.13.3-classroom-eof.1`。补丁含关闭输入不取消执行、关闭后拒绝写入和重复清理测试。

| --------------------- | ------------------------------------------------------ |
| 未认证调用执行接口    | 401                                                    |
| 沙箱进程身份          | 非特权 UID/GID，从 1536 起                             |
| 宿主 SSH 与业务凭据   | 不可见                                                 |
| 工具链目录            | 只读，写入失败                                         |

| 节点重启              | 后续运行成功                                           |

## 50 人集中运行基准

最新一轮创建 50 个真实学生账号，分别保存、发送心跳、提交独立运行，并核对各自输出：

| 指标           |      结果 |
| -------------- | --------: |
| 成功完成       |   50 / 50 |
| 保存与心跳 P95 |     35 ms |
| 运行总耗时 P95 | 13,206 ms |
| 全部完成耗时   | 13,528 ms |
| 峰值排队       |        50 |
| 峰值并行       |         4 |

并发上限由 PostgreSQL 原子领取与全局槽位保护，即使多个 worker 进程也共享限额。默认每名学生最多一个活动任务，队列最多 100。时间包含本轮开发机到节点的实际链路与排队，不能泛化为长期或多个课堂的性能保证。

## 使用边界

当前交付为单文件控制台课堂首版。业务站点在开发机运行，AIM-Radar 部署独立 Linux 评测服务；未声称发布业务站点到公网。交互输入不提供 shell；多文件工程、自动判题、协作编辑、SSO 与内置 AI 属于后续范围。

界面采用 0.5–2 秒轮询与 5 秒心跳，离线判定为 15 秒。本轮 50 人为 HTTP 基准，仍需按实际教学安排开展多台浏览器、真实学员和长期运行试课。长期备份保留和删除策略由部署方制定，当前不会自动清除作品或覆盖数据库。
