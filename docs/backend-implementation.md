# 后端功能与验收

所有业务接口位于 `/api`，使用 HttpOnly、SameSite=Strict 会话 Cookie。角色从服务器账号读取，课堂权限每次查询重新验证；浏览器中的角色或学生编号不能授予权限。密码采用随机盐 scrypt，数据库仅保存会话令牌摘要。登录限速和恢复申请保存在 PostgreSQL。

## 模块

- 账号：管理员创建教师／学生、停用、密码重设与会话撤销；恢复申请由管理员核实身份后处理，不假装发送邮件。首次管理员由 `ADMIN_PASSWORD=... pnpm auth:bootstrap` 创建，重复执行不覆盖密码。
- 课堂：教师创建自己的课堂，配置开放、容量、审批或名册加入、运行、重复提交与归档访问；7 天邀请码支持轮换。成员重复加入不会重复创建，移除即时撤销后续请求权限并停止任务。
- 练习：草稿、发布、关闭、排序、推荐与版本检查。文件名限制为单个 `.cpp`／`.cc`／`.cxx`；更新初始代码不会覆盖已有草稿。
- 草稿：服务器版本号 CAS 更新；冲突返回 409，不静默覆盖。本机备份按账号、课堂和练习隔离，断网明确提示并重试，读取服务器冲突版本前先下载本机备份。教师只读巡视；教师示范草稿独立保存。
- 执行：学生使用已确认保存的 revision 创建不可变代码快照。API 不执行代码；独立 worker 原子领取 PostgreSQL 持久化任务，再调用原生 Linux go-judge。全局 4 槽、每学生最多一个活动任务、队列最多 100；超时失联任务标记平台失败，不自动重跑旧代码。pg-boss 独立保留基础设施自检队列。
- 交互：运行中按行输入、原始 stdout／stderr、真正关闭 stdin 的 EOF、停止、编译诊断、退出原因和历史；编译产物在任务结束清理，节点缓存另设 10 分钟过期。
- 教学：心跳、巡视、当前草稿与历史快照、求助及解决、不可变提交、JSON 作品导出和源文件下载；投屏仅教师授权读取，匿名快照 2 小时有效且可撤销，不暴露学生身份。
- 管理：真实统计、失败任务、账号恢复、审计、运行限额；原生 pg_dump 备份在独立临时数据库恢复验证，现有数据不覆盖，备份留在忽略的 `.local/backups/`。更改配额应用于下一次运行；节点地址与令牌只从服务器环境读取。

## 执行限制

默认 GCC 13.3.0 / C++17，可选择 C++20。编译 CPU 10 秒／墙钟 20 秒／512 MiB；运行 CPU 2 秒／256 MiB；非交互墙钟 5 秒，交互墙钟 60 秒；输出 1 MiB。管理员可在安全范围内调整 CPU、内存、输出与 1–4 槽并发。内存、时间和进程数量由 Linux namespace 与 cgroup 强制限制，网络不可用，编译器目录只读。

## 可复现验收

```sh
pnpm check
pnpm test
pnpm build
pnpm db:migrate
pnpm queue:probe
pnpm acceptance
pnpm capacity:probe
pnpm backup:verify
```

业务验收脚本从本地忽略的 `.local/admin-credentials.json` 登录，创建独立验收账号和课堂，不删除或重置开发者数据。成功后输出写入 `.local/acceptance-result.json` 和 `.local/capacity-result.json`；测试凭据另存权限为 0600 的本地文件。容量探针创建 50 个真实账号，验证保存、心跳与 50 次独立编译运行并核对每人输出，然后归档该测试课堂。

2026-10-25 已验证：角色与成员隔离、审批和去重、题目发布、CAS 冲突、原始诊断、正常输出、交互输入和 EOF、停止、死循环、内存超限、无限输出、非零退出、求助、不可变提交、匿名投屏与撤销、历史导出、归档只读；Linux 节点实际停止后平台失败、恢复后再次运行成功，worker 失联任务回收，备份实际恢复成功。浏览器验收使用独立教师／学生会话。

## 边界

这是单文件控制台课堂首版，不包含自动判题、多文件工程、协作编辑、SSO 或内置 AI。交互不是终端或 shell。实时界面采用 0.5–2 秒轮询与 5 秒心跳；离线判定为 15 秒。50 人数据为本次内网链路的 HTTP 基准，不代表 50 台浏览器和多个课堂的长期试课保证。更大规模与长期备份保留策略需按实际运维安排。
