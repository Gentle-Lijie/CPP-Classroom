# 码上课堂 · UI 设计说明

依据：产品需求 v1.0、开源组件选型 v1.1、IDE 参考截图。范围：Vue 3 前端可点击原型，不新增业务后端、数据库模型或执行接口。

## 设计语言

全站使用纯白页面底色和中性灰文字，主强调色为蓝色（#2563eb），用于主按钮、导航选中态、链接和焦点。图标可使用少量辅助色，警告使用橙色、错误使用红色；成功状态使用文字和勾选图标，不再使用绿色品牌底色。页面采用轻边框与统一的小圆角，去掉大面积彩色底、装饰性引号和宣传式标题。颜色集中在 `apps/web/src/palette.css`，通用视觉状态在 `apps/web/src/interface.css`，编辑器读取相同的颜色变量。品牌名“码上课堂”为本次界面设计命名，可在产品定名前替换。

教师端以定位学生困难为主；学生端以代码编辑为主，IDE 不显示教师管理侧栏。投屏采用独立只读视图，默认匿名。移动端提供折叠菜单、表格横向滚动和纵向 IDE 布局；完整编程仍以桌面使用为主。

## 可验证的交互

- 教师总览的筛选、姓名／学号搜索、详情导航；处理求助后统计即时更新。
- 课堂创建、练习编辑／发布／推荐／关闭、成员添加／审批／移除保存到本机浏览器，并通过 storage 事件更新同源独立窗口；这不代表已实现跨设备同步。
- 表单验证与危险操作确认；对话框使用 Reka UI 的焦点管理与 Escape 关闭行为。
- Monaco 提供 C++ 语法高亮、行号、查找、缩进与键盘编辑；浏览器保存本机草稿，切题与刷新后恢复。
- 所有代码界面复用 `CodeEditor`，各实例底部有独立 clangd 开关，默认关闭，不作为平台级设置。开启后由浏览器 WASM 提供真实 C++17 补全、悬浮说明及版本匹配的错误／警告；关闭或销毁时释放该实例会话、provider 和诊断。加载与兼容性说明见 [浏览器 clangd](browser-clangd.md)。
- 提交将当前代码作为本机独立记录保存，不改写当前草稿；重置前保留可撤销的页面内副本。
- 历史视图展示固定代码与其固定运行上下文；教师默认看当前草稿，选中历史后保持只读快照。
- 投屏默认隐藏身份，可调整字号、切换代码来源与显示结果。
- 可实际下载 `.cpp` 源文件、CSV 名册、JSON 示例作品与上下文。批量导出为便于查看的 JSON 原型格式，正式打包格式待业务阶段接入。

## 状态设计

登录／入班提供登录失败、会话过期、未获授权、邀请过期和课堂关闭场景，使用表单底部状态选择器预览。学生 IDE 提供保存中、已保存到本机、离线／未同步、保存失败和多标签页只读场景。真实网络协议与写入租约尚未接入。

“演示运行”选择固定成功、编译失败、运行中／可输入、运行失败、超时、资源超限与平台失败场景；排队、编译与停止有独立状态。标准输出、标准错误与编译诊断保留来源标签。输入和 EOF 仅操作演示输出，不连接进程。无法确认是否阻塞于输入时使用“运行中／可输入”，不显示确定的等待输入判断。

搜索无结果、待审批为空、无主动提交、无运行输出、备份尚未连接等情况均提供空态。归档与成员移除使用确认框，永久删除未纳入原型。

## 前端与后端边界

人物、课堂、运行指标、展示的执行环境版本与运行日志都是用于设计评审的示例。平台配置页的服务探活读取已有健康 API，clangd 的代码诊断来自浏览器内实际分析。教师和管理员业务页面使用共享的前端示例集合，不构成真实数据隔离；演示身份切换不授予权限。

平台配置草稿按白名单保存在 `cpp-ui-platform-draft-v1`，支持校验、撤销、JSON 导出和未保存离开保护，不修改服务器参数。探活只请求同源 `/api/health` 与 `/api/health/readiness`；go-judge 检测由已有业务服务使用服务端地址和凭据完成，不直接访问表单中的草稿地址。依赖接口返回 503 时仍展示有效的诊断，未配置节点显示“未配置”。自动刷新仅在该页面打开且启用时运行。

原型没有发出课堂业务 API 请求，没有实现身份认证、账号恢复邮件、课堂权限、远程草稿同步、编译执行、交互 EOF、进程清理、任务调度、备份或生产容量验证。GCC 13.2、2,000 ms、256 MB、50 人与保留天数均为展示值，不代表正式环境已经冻结。

本机草稿使用 `cpp-ui-workspace-v2:<classroomId>:<studentId>:<exerciseId>`；提交为独立 JSON 记录，包含源文件名和固定代码。教师示范草稿使用独立的 teacher 身份槽位。原来单课堂原型的 `cpp-ui-draft-<exerciseId>` 草稿会作为回退读取，不删除旧记录。它们仍是单浏览器演示数据，后端接入时需实现真实身份、权限、不可变 Run／Submission、确认式保存与写入冲突保护。页面不把“已提交”称为正确、通过或已掌握。

## 真实本地目录功能

学生工作区使用 File System Access API，运行在 HTTPS 或 localhost 安全上下文中。桌面 Chrome／Edge 可通过原生目录选择器授权 readwrite；不支持的浏览器保留草稿与下载。只访问教师配置的单个 C++ 文件名，拒绝路径、系统设备名和重复文件名，不扫描整个磁盘，也不执行这些文件。

授权目录句柄按课堂保存在 IndexedDB。重进页面只查询权限，不自行弹出权限申请；学生再次点击关联或重新授权后才继续。每次编辑约 750 ms 后写入，串行完成写入和关闭；同源窗口利用 Web Locks 协调同一工作区的写操作。历史快照、多标签页只读示例和归档状态不会写入磁盘。

每 2 秒读取当前文件，磁盘单侧变化时更新编辑器；浏览器和磁盘都有修改时暂停自动写入并展示两个版本。已有同名文件（包括空文件）也先询问保留哪个版本。读取磁盘前保留可下载的浏览器草稿副本，覆盖前重新读取检查磁盘是否再次变化。切题前尝试保存，切题或教师改名后要重新关联目标文件，不会把上一道题的代码写到新文件里，也不会重命名或删除旧文件。

本机源文件限制 1 MB，默认 UTF-8。权限失效、文件被删除／替换、写入失败会明确提示，浏览器草稿保留。外部变化使用轮询而非操作系统文件监听；File System Access API 不提供与外部编辑器之间的原子比较并交换，所以不能承诺零竞争窗口。

本轮验证包含原生 Edge 系统目录选择／授权、测试目录实际创建与写入、外部修改回读及同名文件版本选择；测试目录为忽略的 `.local/ui-directory-probe`。另有对写入冲突、写入失败、大小限制、文件名和 Markdown 安全渲染的自动检查。此验证不涉及 go-judge 或 Linux 执行隔离。

Monaco 按需加载，并在页面销毁时释放编辑器与 model。生产构建会对 Monaco 的大型代码块给出大小提示；后续可结合部署环境优化缓存和加载策略。
