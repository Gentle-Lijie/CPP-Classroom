# 压力测试与图文报告 · 2026-10-25

在线自包含 HTML 报告（6 张真实浏览器截图、交互图表、深浅色、移动布局、脱敏汇总下载）：https://artifact.lijie.space/a/c-jiao-shi-120-zhang-5s1

## 环境与范围

业务 API / worker 为开发机上编译后的原生 Node 常驻进程，前端为 Vite 预览；评测在 AIM-Radar 原生 Linux、16 逻辑 CPU、约 31 GiB 内存运行，通过认证 SSH 隧道接入。固定 4 个执行槽、100 个活动任务，120 个合成账号跨三个课堂。这是 HTTP 并发与少量真实浏览器取证，不是 120 台浏览器长期试课。

## 最终完整复跑

- 47,853 次测量阶段 HTTP 请求；意外 HTTP 错误为 0；边界与重复运行测试的 30 次 409 为预期拒绝。
- 972 次运行逐项核对结果：952 次正常结束、10 次资源超限、5 次超时、5 次编译失败。后 20 个为预期异常样本。
- 100 次边界测试接纳的等待输入任务单独停止清理，不计入上述 972 次结果。
- 50 人持续编辑 120 秒，保存 7,415 次，保存 P95 22 ms；并行完成 532 次运行，最后等待队列排空。
- 教师总览请求 P95 9 ms；峰值实际执行 4，峰值排队 100。
- 混合负载 50/50 符合预期，交互输入与 EOF 20/20 通过。

总耗时包括保存、排队、编译、传输、执行和轮询；程序执行时间不是整体等待时间。网络波动会改变不同轮次结果。本轮未独立量化每阶段占比，不外推长期或公网 SLA。

## 发现并修复的问题

1. 120 次同时提交时，旧入队计数与写入存在竞争窗口，接纳了 102 个任务。现在 API 与 worker 共享事务锁，复测严格接纳 100、拒绝 20。
2. 原流式输出在网关收到超量数据后才取消，混合负载发生正常任务 WebSocket 握手超时。节点已按 `streamOut.max` 在 Linux 读取端限制并截断输出、取消程序并返回 Output Limit Exceeded；网关保留合计字节限制，握手等待调整为 15 秒。新增 Go 流测试与混合回归均通过。
3. 浏览器取证提交额外任务时也会占用全局额度；压力工具明确记录预期队列满拒绝，并在普通负载中使用有界退避。最终完整测量没有额外意外拒绝。

失败样本的脱敏摘要保存在 `docs/stress-baseline-2026-10-25.json`，报告同时展示修复前后证据。当前引擎版本为 `v1.13.3-classroom-eof.2`。

## 复现

```sh
pnpm stress:test
# 仅快速验证边界：node scripts/stress-test.mjs --admission-only
# 定向异常与 EOF：STRESS_ONLY=mixed pnpm stress:test
pnpm stress:report
```

压力工具只清理自己的合成课堂活动任务；不重置数据库。账号和凭据在忽略的 `.local/stress/fixtures.json`（0600）。原始测量数据在 `.local/stress/<时间>/result.json`；自包含页面生成到忽略的 `output/stress-report/index.html`。报告构建器会嵌入 `output/playwright/stress-*.png` 中指定的六张截图，单独运行 HTTP 压力工具不会制造浏览器截图。

`pnpm check`、`pnpm test`（18 项）、`pnpm build`、`pnpm db:migrate`、`pnpm queue:probe` 均通过。Linux 上 Go 流协议测试已通过；报告的筛选、图片放大、主题切换及 390 px 窄屏布局已在真实浏览器验证。
