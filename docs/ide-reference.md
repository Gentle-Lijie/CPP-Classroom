# IDE 布局参考

用户指定参考洛谷在线 IDE。基础工程阶段仅保留参考；本次按“设计每个 UI 界面、不实现后端”的要求，已提供前端工作区原型。

![用户提供的洛谷 IDE 截图](references/luogu-ide.png)

原型保留这些布局特征：

- 全屏浅色工作区，顶部大代码编辑区，下部输入／输出左右分栏。
- 细浅灰分隔线、紧凑工具栏，避免额外的首页、宣传区或侧边管理布局。
- 顶部左侧显示教师为题目配置的源文件名（如 `sum.cpp`），右侧提供字号、下载、重置与受控语言标准提示。课堂标准由教师配置，不让学生修改任意编译参数。
- 底部各自标注“输入”“输出”，运行入口位于输出栏工具条右侧。
- 使用 Monaco 的真实文本编辑能力，下部输入／输出区可通过右下角调整高度。

根据产品需求 F-04，在编辑区右侧增加题面／运行历史面板。桌面为主，窄屏将题面排列在编辑区之后。教师管理导航不进入学生 IDE。

界面使用 Vue 3／TypeScript、shadcn-vue、Tailwind CSS 与按需加载的 Monaco。草稿保存至本机浏览器；运行状态、输入和 EOF 仅为明确标注的交互演示，不执行当前代码。C++17、GCC 版本与资源限制为 UI 示例，正式配置仍需后续验证。

学生可在支持 File System Access API 的桌面 Chromium 浏览器中授权工作目录。目录读写是真实本机功能，与演示运行分离；接入本地目录不会执行代码，也不会获得终端权限。外部修改通过 2 秒轮询检测，冲突时暂停自动写入。
